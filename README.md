# HomeTwin add-on for Home Assistant

Add this repository in Home Assistant under **Settings → Add-ons → Add-on store → ⋮ → Repositories**:

```
https://github.com/all-self-hosted/hometwin-addon
```

then install **HomeTwin**. It runs on amd64 and aarch64 (a Raspberry Pi 4 or 5 is fine), opens in the sidebar and connects to that Home Assistant by itself.

HomeTwin itself: https://github.com/all-self-hosted/hometwin (MIT).
